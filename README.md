## 🚀 Featured Projects

### 🏡 Amihan Staycation

**Staycation booking and management platform**  
**Client:** Azure Staycation Urban Residence

<p>
  <a href="https://amihanstaycation.vercel.app"><img src="https://img.shields.io/badge/Live_Website-Visit-2E8B57?style=for-the-badge&logo=vercel&logoColor=white" alt="Visit Amihan Staycation website" /></a>
  <a href="https://github.com/Project2START/amihan-staycation"><img src="https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge&logo=github&logoColor=white" alt="Amihan Staycation GitHub repository" /></a>
</p>

A client project that lets guests browse staycation listings, book accommodations, and share reviews. Admin and agent dashboards support reservation and user management.

- 🔐 Role-based access for users, admins, and agents.
- 🗓️ Booking creation and history tracking.
- 💳 Payment-method management, reviews, and ratings.
- 🔔 Notifications and real-time updates.

**Stack:** Next.js, React, TypeScript, Tailwind CSS, Material UI, Express, PostgreSQL, Prisma, Supabase, Socket.IO.

### 🚨 RescueLink Taguig

**Emergency response, incident logging, and civilian coordination platform**  
**Client:** Command Center of Taguig

<p>
  <a href="https://rescuelinktaguig.com"><img src="https://img.shields.io/badge/Website-Visit-2E8B57?style=for-the-badge&logo=googlechrome&logoColor=white" alt="Visit RescueLink Taguig website" /></a>
  <img src="https://img.shields.io/badge/Project-Completed-2E8B57?style=for-the-badge" alt="Project completed" />
</p>

A platform developed for the Command Center of Taguig to streamline communication between residents and emergency response agencies, including police, fire, medical, and DRRMO teams.

- 🗺️ Real-time incident mapping using React-Leaflet and GeoJSON.
- 📡 WebSocket-powered messaging and live emergency coordination.
- 🌦️ Weather and flood-risk monitoring integrations.
- 🛡️ Role-based access control for protected features.
- 🚒 Resource tracking and assignment across agencies.

**Stack:** TypeScript, React, Next.js, Node.js, NestJS/Express, PostgreSQL, Prisma, Socket.IO, WebRTC, Docker, AWS.
